# tea

下载 [Releases](https://github.com/ruoyeyu/tea/releases/latest) 中的 `.tgz` 后：

```sh
npm install --global ./tea-6.8.0.tgz
tea --help
tea setup --client opencode
```

需要 Node.js，推荐 `.nvmrc` 指定版本。安装时联网下载依赖，无须编译项目。
源码构建和客户端配置见 [安装](docs/installation.md)。
